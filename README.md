# Dastarkhan · دسترخوان
Family food planner – weekly meals, shopping list, nutrition and food budget, in English and Dari.

## Put it online with GitHub Pages (free)
1. Sign in to github.com with your personal account.
2. Click **+ → New repository**. Name it `dastarkhan`, choose **Public**, and click **Create repository**.
3. Click **uploading an existing file**. Drag in everything inside this folder: `index.html`, `sw.js`, `manifest.webmanifest`, `README.md` and the `icons` folder. Click **Commit changes**.
4. Go to **Settings → Pages**. Under *Branch*, choose **main** and **/(root)**, then click **Save**.
5. After 1–2 minutes the app is live at `https://YOUR-USERNAME.github.io/dastarkhan/`.

## Install on phones
- **Android (Chrome):** open the link, then tap **⋮ → Install app** (or **Add to Home screen**).
- **iPhone (Safari):** open the link, then tap **Share → Add to Home Screen**.

## Update the app
Upload the new files to the same repository with **Add file → Upload files** and **Commit changes**. The link stays the same, and phones get the update next time they open the app with internet.

## Good to know
- Each phone keeps its own data. To share a plan or move to a new phone, use **Family → Save / send backup**, then **Load a backup file** on the other phone.
- The repository is public, so anyone can see the app's code, but not your family's data.

## راه‌اندازی رایگان با GitHub Pages
۱. با حساب شخصی خود وارد github.com شوید.
۲. **+ ← New repository** را بزنید. نام آن را `dastarkhan` بگذارید، **Public** را انتخاب کنید و **Create repository** را بزنید.
۳. **uploading an existing file** را بزنید. همهٔ چیزهای داخل این پوشه را بکشید و بیندازید: `index.html`، `sw.js`، `manifest.webmanifest`، `README.md` و پوشهٔ `icons`. بعد **Commit changes** را بزنید.
۴. به **Settings ← Pages** بروید. در بخش *Branch* گزینهٔ **main** و **/(root)** را انتخاب کنید و **Save** را بزنید.
۵. بعد از ۱ تا ۲ دقیقه اپ در این آدرس آماده است: `https://YOUR-USERNAME.github.io/dastarkhan/`

## نصب روی تلفون
- **اندروید (Chrome):** لینک را باز کنید و **⋮ ← Install app** (یا **Add to Home screen**) را بزنید.
- **آیفون (Safari):** لینک را باز کنید و **Share ← Add to Home Screen** را بزنید.

## تازه کردن اپ
فایل‌های نو را با **Add file ← Upload files** در همان repository بار کنید و **Commit changes** را بزنید. لینک تغییر نمی‌کند.

## یادداشت
- معلومات هر تلفون در همان تلفون ذخیره است. برای فرستادن پلان به خانواده یا انتقال به تلفون نو: **خانواده ← ذخیره یا فرستادن پشتیبان**، و در تلفون دیگر **باز کردن فایل پشتیبان**.
- repository عمومی است؛ کود اپ دیده می‌شود، اما معلومات خانوادهٔ شما نه.
